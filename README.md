
# CyberSafe AI - Social Awareness Campaign

## About
CyberSafe AI is a Python-based awareness
assistant that provides basic cyber safety
tips using keyword detection.

## Objectives
- Create awareness about online scams.
- Promote strong password practices.
- Protect personal information.
- Encourage safe social media usage.
- Raise awareness about cyberbullying.

## Technologies
- Python
- Keyword-based response system
- GitHub

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run: python main.py
5. Enter a cyber safety question.
6. Type exit to close the program.

## Future Enhancement
- Add a graphical user interface.
- Add Tamil and English support.
- Integrate an AI API for intelligent responses.
